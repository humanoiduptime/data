# HumanoidUptime Public Data v1.4.0

Snapshot: 2026-09-04  
Dataset schema: `humanoiduptime-public-data` version `1`

Version 1.4.0 adds persistent Record ID resolution and a public lifecycle registry without changing the underlying evidence conclusions.

## Changes

- Adds permanent /id/HU-R… identifiers for all public Reliability Records.
- Adds a versioned identity lifecycle registry covering active, withdrawn, merged and superseded states.
- Uses persistent Record ID URLs in Plain Text, CSL JSON and Schema.org citation projections.

## Distributions

- versioned JSON containing the complete public projection;
- deterministic CSV ZIP containing 9 linked CSV tables, the CSV manifest
  and data dictionary;
- release manifest binding both distributions to this release;
- release checksums covering both distributions and the manifest.

The files in tag `v1.4.0` are canonical. Any GitHub Release
attachments must match their published SHA-256 checksums.

## Verify

```bash
node scripts/validate.mjs
(cd data && sha256sum -c humanoiduptime-public-data-v1.4.0-2026-09-04-release-checksums.sha256)
```

## Boundaries

This is a reviewed public projection, not the editorial database. It excludes private candidates, raw submissions, review schedules, infrastructure data and retained third-party source bodies. It does not imply HU-RDP conformance, independent verification or a cross-model performance ranking.
