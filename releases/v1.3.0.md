# HumanoidUptime Public Data v1.3.0

Snapshot: 2026-09-04  
Dataset schema: `humanoiduptime-public-data` version `1`

Version 1.3.0 adds canonical record and dataset citation projections without changing the underlying evidence conclusions.

## Changes

- Adds one canonical citation identity for the dataset and each public Reliability Record.
- Generates reader-facing Plain Text, CSL JSON, JSON-LD, CITATION.cff and release-note output from that shared identity.
- Adds a compact record citation interface and dataset citation on the Coverage page.

## Distributions

- versioned JSON containing the complete public projection;
- deterministic CSV ZIP containing eight linked CSV tables, the CSV manifest
  and data dictionary;
- release manifest binding both distributions to this release;
- release checksums covering both distributions and the manifest.

The files in tag `v1.3.0` are canonical. Any GitHub Release
attachments must match their published SHA-256 checksums.

## Verify

```bash
node scripts/validate.mjs
(cd data && sha256sum -c humanoiduptime-public-data-v1.3.0-2026-09-04-release-checksums.sha256)
```

## Preferred dataset citation

## Boundaries

This is a reviewed public projection, not the editorial database. It excludes private candidates, raw submissions, review schedules, infrastructure data and retained third-party source bodies. It does not imply HU-RDP conformance, independent verification or a cross-model performance ranking.
