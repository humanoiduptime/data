# HumanoidUptime Public Data v1.2.1

Snapshot: 2026-09-04  
Dataset schema: `humanoiduptime-public-data` version `1`

Version 1.2.1 is a packaging and release-integrity patch. It does not add new
evidence, records or conclusions relative to v1.2.0.

## Distributions

- versioned JSON containing the complete public projection;
- deterministic CSV ZIP containing eight linked CSV tables, the CSV manifest
  and data dictionary;
- release manifest binding both distributions to this release;
- release checksums covering both distributions and the manifest.

Individual versioned CSV files remain available in the repository. The files in
tag `v1.2.1` are canonical. Any GitHub Release attachments must match their
published SHA-256 checksums.

## Verify

```bash
node scripts/validate.mjs
(cd data && sha256sum -c humanoiduptime-public-data-v1.2.1-2026-09-04-release-checksums.sha256)
```

## Boundaries

This is a reviewed public projection, not the editorial database. It excludes
private candidates, raw submissions, review schedules, infrastructure data and
retained third-party source bodies. It does not imply HU-RDP conformance,
independent verification or a cross-model performance ranking.
